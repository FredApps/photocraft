### Problem
`cargo xtask i18n-coverage` reports Simplified Chinese at 14 keys short of complete. Fourteen counted messages had no `@plural` entry, so with the Simplified Chinese interface they appeared in English, for example:
- "Played 3 steps";
- "Imported 2 brushes from …";
- "Saved for Web: 5 files";
- the Layer Comps "layers recorded by this comp were deleted" warning;
- the Info panel's "{n} sample points removed".

The same keys are also missing from fr (covered by #4474), id, ko and zh-hans; pl is #7150. This PR is Simplified Chinese only.

### Solution
`crates/ui-egui/src/i18n/zh-hans.tsv` adds the 14 `@plural` entries. Chinese has no plural forms (`plural_none`), so each entry has one form, with the measure words the catalog's other counted messages use (个, 条).

Wording reuses the terms the catalog already has: 色板, 画笔, 预设, 切片, 取样点, 智能对象, 图层复合, 存储为 Web 所用格式, 警告, 步骤; requests start with 请 as elsewhere in the catalog. The entries were written from the meaning of the English text in ordinary vocabulary (clean-room, as the catalog header asks). Simplified Chinese coverage is now 100%.

### Tests
`i18n::tests::simplified_chinese_counted_messages_are_translated` checks three of the messages: a plain count, one with a `{group}` placeholder filled afterwards, and a noun-only count. It fails without the catalog entries, which fall back to English.
