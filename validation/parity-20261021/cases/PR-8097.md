Adds 131 Brazilian Portuguese strings (I'm a native speaker). They are labels the UI translates at runtime through `tl!(…)` or `fmt(tl!(template), …)`, which `i18n-coverage` can't list, so in pt-BR they still showed in English. Other catalogs already had them.

| Area | Examples |
|---|---|
| Channels panel menu | Novo canal…, Mesclar canal de cor especial, Converter em canal alfa, Sair da máscara rápida, A cor indica áreas mascaradas |
| Layer Style › Blending Options | Mesclagem geral, Raso / Profundo, A máscara de camada oculta os efeitos, Esta camada:, Camada subjacente: |
| Canvas right-click menus | Cinza-escuro, Criar demarcador de trabalho…, Transformação livre do demarcador, Copiar traçado completo |
| Color Picker titles | Seletor de cores (Cor de primeiro plano) |
| Rasterize prompts | Esta camada de texto precisa ser rasterizada antes de continuar. … |
| GPU and monitor status | Adaptador gráfico: {adapter}, Perfil do monitor em uso: {profile} |
| Status messages | Preferências salvas, Falha ao reproduzir a ação: {error}, {shortcut} atribuído. |
| Liquify tool tooltips | Deformação para frente, Torcer no sentido horário, Franzir, Inflar |

Terms follow the catalog's own wording: demarcador for path, canal de cor especial for spot channel, Mesclar for Merge, Traçado for stroke, Seletor de cores, Configurações de cores.

Each source string was checked in the code: it is passed through `tl!` (directly, through a template, or by the helper that draws it, such as `item()` in the Channels panel or `tl!(tool.label())` in Liquify). I left out strings that are only used as untranslated accessibility labels (Commit transform, Cancel transform) and Liquify labels that aren't drawn from `label()` (Freeze Lasso, Reconstruct All, Mask None).

Only `pt-br.tsv` changes (131 rows in labelled sections at the end). Every row has three columns, `{placeholders}` match the source, there are no duplicate keys, and `cargo xtask i18n-coverage` still reports pt-br at 1909/1909. No proprietary resources were used.
