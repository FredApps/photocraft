Fixes #4402
Addresses #4497

**Change:**
"Show Transform Controls" is now enabled by default for the Move tool. Unticking it is still remembered in preferences.

**Why:**
- #4402 requested this as the default
- #4497 showed Photopea with controls on vs PhotoCraft with them off - same root cause

**Solution:**
- Changed `ToolOptions::move_show_transform` default from `false` to `true`
- Added `#[serde(default = "yes")]` so older saved state without the field gets `true`

**Test changes:**
- 4 tests now explicitly disable controls where they grab tiny layers or corner pixels that handles would cover
- 2 pre-existing failures in `tests/layout_perf.rs` remain (already failing on clean main)

**Testing:**
- New test `show_transform_controls_is_on_by_default_and_deserialized_as_true`
- All ui-egui lib tests pass (2316 tests)
