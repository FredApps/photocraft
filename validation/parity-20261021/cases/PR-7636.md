Closes #6698.

The Layer Style dialog left out glow settings that the engine already supports (`layer.layerStyle.innerGlow` / `outerGlow` take `technique` and `range`):

- **Inner Glow** had no Technique and no Range.
- **Outer Glow** had no Technique, and showed Range before Contour, where Photoshop shows it after.

Since the issue was filed, Source and Choke were added. Anti-aliased is the checkbox beside Contour.

### Change

- **Inner Glow fields**, in Photoshop 2025's order: Blend Mode, Opacity, Color, **Technique** (Softer / Precise), Source, Choke, Size, Contour (+ Anti-aliased), **Range**, Noise.
- **Outer Glow fields:** Blend Mode, Opacity, Color, **Technique**, Spread, Size, Contour, **Range**, Noise.
- **Loading:** the dialog now reads each glow's technique, so OK keeps a Precise glow Precise. It already read the range.
- **Engine defaults:** both glows' defaults gain `technique: "softer"`, Inner Glow's gains `range: 50`, and the `innerGlow` command docs now list `range`. These are Photoshop's factory values.

Not in this PR: **Jitter**. It only acts on gradient glows, which the dialog doesn't offer yet (its Color field is a single swatch), so I left it for a follow-up with the gradient fill.

### Tests

- New: `glows_show_and_keep_technique_and_range`. It checks both glows' field order, that a Precise Inner Glow at 30 % Range and a Precise Outer Glow show those values in the dialog, and that OK keeps them. It fails without the fix: the Inner Glow fields lack Technique and Range.
- `cargo fmt`, `clippy -D warnings` (engine and ui-egui), the engine and ui-egui suites (5,207 tests), `cargo xtask wasm` and `cargo xtask layers` pass.

### Verified in the app

On macOS 27, side by side with Photoshop 2025's Layer › Layer Style › Inner Glow… and Outer Glow…:

- **Inner Glow:** Technique (Softer) sits above Source, and Range (50 %) below Contour, as in Photoshop's Elements and Quality groups.
- **Persistence:** I switched the Inner Glow to Precise, pressed OK and reopened it; it still shows Precise.
- **Outer Glow:** shows Technique above Spread.
