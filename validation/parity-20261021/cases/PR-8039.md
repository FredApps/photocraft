## Problem

#7899 reports that a Softer Outer Glow falls to zero at `Size`, while Photoshop keeps a short fading tail. The current two-box tent has finite support, which causes the hard cutoff.

## Change

- Preserve the existing tent profile and add a short, range-scaled tail only to Softer outer glows.
- Derive the tail from the shape's Euclidean outside-distance field, max-combine it with the existing blur, and include its support in CPU effect margins.
- Use the same tail stage in the GPU compositor. Inner glows and Precise glows are unchanged.

Reference comparison from the issue: [Photoshop vs PhotoCraft](https://github.com/user-attachments/assets/96cdaebe-4752-47af-b51e-de41d8adea8f).
