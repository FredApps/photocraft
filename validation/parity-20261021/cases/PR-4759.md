## Procedure

1. Create a small deterministic high-contrast/alpha-gradient document using the supplied neutral grids. In Photoshop add the exact effect/filter/mode from this PR with recorded parameters; save an editable PSD plus lossless reference.
2. Open/apply the same configuration in PhotoCraft, first with the normal GPU compositor and then the documented CPU fallback. Force a redraw; capture full image and 100%/800% edge crops.
3. Compare with Photoshop as well as CPU versus GPU. Exercise minimum/default/maximum and the named boundary case, soft alpha, masks, clipping/group context, and supported 8/16/32-bit depths.
4. Undo/Redo, change a parameter, hide/show the layer/effect, save and reopen in both apps. Ensure the result is not just an unchanged cached composite.
5. Measure pixel differences using registered lossless exports and state an agreed tolerance before signoff. Preserve any GPU-adapter skip as NOT_EXERCISED.
