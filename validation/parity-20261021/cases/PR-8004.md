Part of #7537.

**What the issue showed.** On Windows 11 ARM64 with 0.10.0, editing Layer Style › Inner Shadow and then drawing made PhotoCraft exit with no error window. The log shows the Vulkan driver losing the device ("driver implementation is at fault"), egui-wgpu panicking while it drew the window on the lost device, and then a second panic in wgpu-hal's Vulkan swapchain. The reporter then set Preferences › Performance › GPU Backend to **DirectX 12** and [could not reproduce it any more](https://github.com/storytold/photocraft/issues/7537#issuecomment-6263392879).

**Change.** On Windows, `auto` already ranks a DX12 adapter before Vulkan for Intel, whose Vulkan driver is known to crash. This PR applies the same rule to Qualcomm, the GPU in Windows on ARM PCs, so these machines start on DX12 without anyone changing a setting:

- `dx12_first_on_windows(vendor)` lists the makers that get DX12 first: Intel (`0x8086`) and Qualcomm. Qualcomm has two ids: `0x5143` from its Vulkan driver and `0x4D4F4351` ("QCOM") from DXGI. Both are matched, so the DX12 adapter wins.
- `intel_dx12_applied` becomes `dx12_default_applied`. It returns the maker's name, so the System Info note says "Qualcomm graphics on Windows: using DirectX 12 …" or "Intel graphics …".
- An explicit backend preference, `WGPU_BACKEND` and `--safe-gpu` are unchanged. Nothing changes off Windows.
- `docs/development.md` now mentions Qualcomm next to the Intel default.

**Not in this PR.** The window still can't survive a lost device on any backend. Open PR #6464 handles that by saving documents for recovery and closing cleanly. Issue #7537 stays open for it.

**Caveat.** The log doesn't name the adapter. The Qualcomm part comes from the platform: Windows on ARM devices ship Adreno GPUs. I have no ARM64 device, so this hasn't been run on one.

**Tests.** New unit test `qualcomm_on_windows_defaults_to_dx12` in `apps/photocraft/src/gpu_startup.rs`, and the Intel test now uses the renamed helper. Tests were **not run locally** and nothing was built; CI will verify.
