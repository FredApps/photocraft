Fixes #7515, fixes #7516, fixes #7517, fixes #7518, fixes #7519.

Two problems in the Free Transform / Transform Selection `.atn` mapping.

- **#7515, import:** the export writes a Transform Selection's interpolation (`Intr`), but the importer read it only for a layer transform, so a selection replayed with the default resampler. It's now read for both targets.
- **#7516–#7519, export:** the descriptor scales and rotates about the centre (`FTcs` average), with no skew and no warp. The importer already refuses `Skew` and `Usng`. A step with another reference point, a skew or a warp exported as a plain scale and replayed differently. Such steps are now refused, as other transforms the descriptor can't hold already are: strict export fails and a partial export skips the step. This applies to Transform Selection and Free Transform, which share the descriptor.
  - Refused: a `reference` other than `"center"` (named or `[x, y]`), a non-zero `skewX` or `skewY`, or a `warp` / `style` / `mesh` / `grid`.
  - Also refused: `corners`, Transform Selection's alias for `quad`, which slipped past the existing `quad` check.
  - Defaults (`"reference": "center"`, zero skew) still export.

I didn't map other reference points to Photoshop's `QCSt` values, because which value means which point can't be checked offline. Mapping them later would only need the import and export pair and a round-trip test.
