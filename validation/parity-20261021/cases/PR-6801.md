Fixes #6744 (the Deselect part).

## Cause
`select.deselect` is enabled only when there is a selection. Action playback runs each step through `Session::execute`, which checks that precondition first, so an action whose first step is Deselect stopped at step 1 with "no selection" whenever nothing was selected. In Photoshop, Deselect with nothing selected is a silent no-op during playback.

## Fix
- Action playback (`actions_cmds::run_recorded`) treats a Deselect step with an open document and no selection as done and plays on.
- `select.deselect`'s `run` returns `Ok` without touching the document or adding a history step when there is no selection (defensive; `enabled` is unchanged, so the menu item still greys out like Photoshop's).

## Tests
- `actions_cmds::tests::deselect_with_nothing_selected_is_a_noop_in_playback`: Deselect's `run` with no selection returns `Ok` and adds no history step; an action `[Deselect, New Layer]` plays both steps.

## Not in this PR
The other problems in #6744: the `layer.rasterize` step failing after a layer copy with no selection, and a playback mode that skips steps whose precondition does not apply.
