Fixes #7859



### Problem

The Slice Select tool used Lucide's `square-dashed-mouse-pointer`, the same icon as the Object Selection tool. In the toolbar and its flyout, the two tools looked identical. Photoshop's Slice Select icon is the Slice knife with a pointer.



### Solution

- **New icon:** `assets/icons/slice-select.svg` is an original glyph, as the author suggested: the Slice tool's knife (from our own `slice-knife.svg`), moved up and right, with an arrow pointer below left.

  - It uses the same 24-unit grid and stroke style as the other icons.

  - It is registered in `icon_data.rs`, and `icons::tool_icon` maps `Tool::SliceSelect` to it.

- **Attribution:** `ATTRIBUTION.md` lists it as original work, like `slice-knife.svg`, and excludes it from the Lucide row.



Object Selection keeps its icon.



### Tests

`icons::tests::slice_select_icon_is_its_own`:

- Slice Select's icon name differs from Object Selection's and Slice's;

- rasterized at 14 and 28 px, it shares less than half its ink with Object Selection's, measured the same way as the existing Quick Selection vs Ellipse Marquee test;

- it shares the knife with Slice's on purpose (as in Photoshop), and at least 30 % of its ink (the pointer) is its own.



Checked in the toolbar with the offscreen `snapshot` example.



It fails without the change: Slice Select and Object Selection had the same icon.
