### Problem
`cargo xtask i18n-coverage` reports Polish at 1846/1860. Fourteen counted messages had no `@plural` entry, so with the Polish interface they appeared in English, for example:
- "Played 3 steps";
- "Imported 2 brushes from …";
- "Saved for Web: 5 files";
- the Layer Comps "layers recorded by this comp were deleted" warning;
- the Info panel's "{n} sample points removed".

The same 14 keys are also missing from fr, id, ko and zh-hans.

### Solution
`crates/ui-egui/src/i18n/pl.tsv` adds the 14 `@plural` entries with Polish's three forms (1 · 2–4 except 12–14 · the rest, `plural_polish`).

Wording follows the terms the catalog already uses:
- **Presets:** "ustawienie wstępne", and "ustawienia wstępne pędzli" for brush presets.
- **Smart objects:** "połączony obiekt inteligentny".
- **Other terms:** "pędzle", "plasterki", "kompozycje warstw", "punkty próbkowania", "Zapisz dla Internetu".
- **Swatches** are "próbka koloru / próbki kolorów", because the catalog already uses "Próbki" for the Swatches panel and "próbka" for samples.

The entries were written from the meaning of the English text in ordinary Polish (clean-room, as the catalog header asks). Polish coverage is now 100% (`cargo xtask i18n-coverage`: pl 1863/1863 on current `main`).

### Tests
`i18n::tests::polish_counted_messages_use_all_three_forms` checks that "Played {n} steps" reads correctly for 1, 3, 5, 12 and 22 (one, few, many, the 12–14 exception, and 22 back to few), together with a `{group}` message and a noun-only message. It fails without the catalog entries, which fall back to English.
