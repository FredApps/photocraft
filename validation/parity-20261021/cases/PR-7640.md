Closes #7268.

A right-click on the canvas with the Quick Selection tool opened the Brush Preset picker (size and hardness). `paint_mouse::has_brush_picker` includes Quick Selection, because it has the options-bar brush chip, and that same check decided what the canvas right-click opened. `canvas_tool_menu::applies`, which lists the tools whose right-click opens the selection menu, didn't include it.

In Photoshop 2025, a right-click with Quick Selection opens the same menus as the other selection tools:

- **With a selection:** Deselect, Select Inverse, Feather…, Select and Mask…, Save Selection…, Make Work Path…, Layer Via Copy, Layer Via Cut, Free Transform, Transform Selection, Fill…, Stroke… and so on.
- **Without one:** a context menu.

Its brush is set from the options bar.

### Change

- `canvas_tool_menu::applies` now includes `Tool::QuickSelection`.
- A new `paint_mouse::right_click_picker`: the tools with a picker and no canvas menu. The canvas right-click (`canvas_buttons`) and the control channel's secondary pointer (`pointer_secondary`) use it. `has_brush_picker` still decides who has the chip, so the Quick Selection tool's chip opens and closes the picker as before.

### Tests

- New: `quick_selection_chip_toggles_the_picker_and_right_click_opens_the_selection_menu`. The chip opens and closes the picker; a right-click opens the selection menu and no picker. It fails without the fix.
- The canvas-menu tests that listed Quick Selection with the brush tools (`brush_picker_taps_…`, `brush_chip_toggles_…`, `control_channel_opening_uses_the_same_dismissal_guard`) now expect the selection menu for it. `secondary_taps_keep_selection_menus_open` covers it with and without a selection.
- `cargo fmt`, `clippy -D warnings`, the ui-egui suite (3,193 tests), `cargo xtask wasm` and `cargo xtask layers` pass.

### Verified in the app

On macOS 27 with a release build, side by side with Photoshop 2025:

- **With a selection:** a Quick Selection right-click opens the selection menu with the same rows as Photoshop's (Deselect … Content-Aware Fill…).
- **The chip:** still opens the Brush Preset picker.
- **Without a selection:** a right-click opens PhotoCraft's existing no-selection menu, the one the other selection tools use (Select All, Reselect, Color Range…, Load Selection…). Photoshop's no-selection menu also lists layer commands for every selection tool. That's outside this change.
