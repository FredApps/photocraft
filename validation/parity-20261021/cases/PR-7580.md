## Procedure

1. Author a small editable reference document in Photoshop that actually contains the affected mode, metadata, block, layer kind or format feature. Save a lossless rendered reference and record dimensions, bit depth, ICC, resolution and feature settings.
2. Open the same immutable input in PhotoCraft; capture the image, Layers/Channels and any warning. Force a re-render by a reversible edit so a cached preview cannot mask a broken decoder/compositor.
3. Perform the exact open/save/export/replace operation in the target below. Reopen the output in PhotoCraft and Photoshop; inspect editability, settings, metadata and pixel/alpha geometry, not just that a file was written.
4. Repeat relevant RGB/Gray/CMYK and 8/16/32-bit supported cases, plus an ordinary unaffected control. Record unsupported combinations as such without silently converting them.
5. Check cancellation, overwrite and failed-output atomicity using disposable copies. Preserve before/after files and hashes; use an independent parser/native wire test for properties that are not visible in the GUI.

## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Saving an existing directory `.pcraft` without replacement previews deletes its old thumbnail and composite before publishing the new manifest. If manifest replacement fails, the saved manifest still references files that have already been deleted.

Commit the manifest first, then remove omitted previews as best-effort housekeeping, matching unreferenced-object cleanup. A locked leftover is retried on a later save; it cannot turn an already committed save into a reported failure. Existing path validation and directory-handle protections remain in place.

Fixes #7549. This does not fix replacement previews in #7548.
