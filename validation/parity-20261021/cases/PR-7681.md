## Pinned upstream reproduction and regression specification

Fixes #7672.

Strict Save Actions could export a Selective Color step such as `{"method":"absolute","colors":"reds","cyan":35}` without warnings, then replay it as an identity adjustment after importing the ATN. The converter only serialized per-range arrays and dropped the accepted single-range scalar form.

Normalize export parameters with the existing command parser. This preserves component-wise scalar overrides, the `relative` alias's precedence over `method`, null/default handling and percentage clamping. Serialize the supplied ranges with their effective values. Invalid Selective Color parameters now fail strict export, or are reported when `skipUnsupported` is requested. Both destructive adjustments and new adjustment layers use this converter.

The new integration target compares actual pixels after direct execution, native action replay, and strict ATN export/import/replay. It covers 225 command/depth cases across all nine ranges, relative/absolute modes, 8/16/32-bit documents, mixed scalar/array input, defaults, nulls, clamping and existing array controls. Fourteen malformed command/parameter sets exercise strict refusal and skip reporting. The fixture is synthetic, and the scalar cases must visibly change it.
