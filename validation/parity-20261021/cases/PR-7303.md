## Summary
In Preferences > Keyboard Shortcuts, pressing Shift while recording a shortcut was ignored, as if it weren't held (#7190). The capture now tracks modifier keys across frames and walks the key events, so Shift (and Ctrl/Alt) count even when egui reports no modifier bits on those events.

## What changed
- `crates/ui-egui/src/prefs_ui.rs`: shortcut capture remembers held modifier keys between frames and reads them from the key events themselves.
- `crates/ui-egui/src/shortcut_capture_tests.rs`: new `shift_is_recorded_when_modifier_key_events_carry_no_bits` test; the existing Ctrl+K capture test still passes.
