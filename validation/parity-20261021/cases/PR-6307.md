## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

what happens: a DDS with an alpha channel opens fully transparent. for the
reported DXT5 AO map every one of the 262,144 alpha values is zero, so the
canvas is blank although the RGB data is intact.

root cause: `import_flat` in `crates/io/src/flat.rs` kept the decoded alpha as
layer transparency for every flat format except Targa, which #2225
special-cased (`tga_alpha_to_channel`): a 32-bit TGA opens as a locked opaque
"Background" layer with the fourth byte preserved as an "Alpha 1" channel.
DDS was the remaining format with the old behavior.

the fix: DDS takes the same path as Targa. a DDS with an alpha channel now
opens as a locked opaque "Background" layer plus an "Alpha 1" document channel
holding the original alpha — the same default as Photoshop's DDS import with
"Load Transparency" unchecked. nothing is discarded.
