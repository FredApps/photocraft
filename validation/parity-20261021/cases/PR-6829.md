## Pinned upstream reproduction and regression specification

Fixes #6784.



A recorded Shift-click on a layer is stored in `.atn` as `select` with `selectionModifier: addToSelectionContinuous`. The importer only knew `addToSelection` and `removeFromSelection`, so this fell through to a plain select, and a following Group Layers grouped one layer.



- `select_from`: `addToSelectionContinuous` now maps to `layer.select` with `mode: "range"` (the mode `layer.select` already supports for Shift-click in the Layers panel).

- `select_to`: `mode: "range"` now exports back as `addToSelectionContinuous`. Before, export refused it.

- Test: added a `range` case to `every_mapped_command_exports_and_imports_back`, next to the existing `add` case. Without the fix, the export returns nothing and the test fails.
