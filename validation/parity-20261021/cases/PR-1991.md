## Summary

Partially addresses #1951.

PhotoCraft persists recorded actions internally, but users
cannot conveniently export their action libraries or import
actions from another installation.

This adds JSON import/export through the engine commands `actions.import` and `actions.export`, using PhotoCraft's existing versioned ActionsFile format. The Actions panel, CLI, and MCP share the engine implementation.

## Changes

### Actions Panel

Add an Actions menu containing:

- Load Actions… (supports JSON alongside the existing ATN path)
- Save Actions… (.json)

The panel keeps file selection and status messages; merge, rename, validation, nested-reference retargeting, and serialization run in the engine. Menu labels and status strings are translated.

### Export

- Export the current action library as JSON.
- Use the existing ActionsFile version 1 format.
- Preserve action names, commands, parameters, and order.
- Enforce the existing 16 MiB Actions file limit.
- Report successful exports through the status system.

### Import

- Read versioned Actions JSON files.
- Preserve existing actions.
- Append new actions to the library.
- Skip already imported identical actions.
- Rename conflicting imports using `(Imported N)`.
- Retarget nested action references after renaming.
- Support nested references by action name or imported index.
- Update the action-library revision for persistence.
- Prevent imports while actions are recording or playing.

### File Validation

Reject:

- Invalid JSON.
- Unsupported file versions.
- Files exceeding the 16 MiB limit.
- Empty or duplicate action names.
- Excessively long action names.
- More than 1,024 imported actions.
- More than 10,000 steps per action.
- Invalid nested action indexes.

### Regression Tests

Added tests for:

- Export/import round-trip preservation.
- Repeated imports without creating duplicates.
- Duplicate-name handling.
- Nested action reference preservation.
- Invalid JSON and unsupported versions.
- Duplicate action names.
- Import rejection during recording.
- Existing action preservation after failed imports.

## Compatibility

This uses PhotoCraft's native JSON Actions format.

It does not add Photoshop `.atn` import support.
