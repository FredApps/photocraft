## Pinned upstream reproduction and regression specification

Refs storytold/PhotoCraft#5745. Split out of #5816 per review.

**Cause:** Auto-Blend put a layer mask straight onto the Background when it was among the selected layers. #5745's two-photo document ended with a masked Background, which the Background can't have.

**Fix:** before writing each mask, call the existing `extra_cmds::background_to_layer_for_mask`, which turns the Background into Layer 0 as Photoshop does. Other layers are left alone.

**Test:** `auto_blend_turns_the_background_into_a_layer`: after Auto-Blend the Background is a normal layer with a mask, and undo restores it.
