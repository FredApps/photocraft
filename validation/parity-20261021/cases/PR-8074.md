## Problem
Transform sessions used hard-coded interpolation defaults, so choosing Nearest Neighbor only affected the current transform. The next transform opened with Bicubic (or Bilinear for selection transforms).

## Change
All transform entry points now read the existing General › Image Interpolation preference. Changing the options-bar interpolation updates that preference, so later transforms reuse the selected mode. The shared preference also supplies Image Size's default. A UI regression test selects Nearest Neighbor, commits a transform, opens another, and checks that the selection remains.
