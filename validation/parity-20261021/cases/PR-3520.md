## Problem

In the Studio Dark theme, the toolbar displays foreground and background colors as two large overlapping circles.

Issue #3494 requests restoring the compact square color chips used by the standard theme.

## Root cause

The Studio Dark palette enables `round_chips`, selecting the large circular layout in the toolbar's color-chip renderer.

The existing renderer already supports square chips.

## Changes

- Disable `round_chips` specifically for Studio Dark.
- Reuse the existing overlapping square-chip layout.
- Preserve foreground/background color selection and the existing color-picker interactions.
- Leave Studio Light and other theme palettes unchanged.

## Tests

Added a regression test verifying:
- Studio Dark selects square color chips.
- Studio Light retains its existing circular layout.
- The Pro theme retains its existing square layout.

The test has not been executed locally. Visual verification and CI validation are pending.
