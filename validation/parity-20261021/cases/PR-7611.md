## Cause
The `select.refineEdge` ATN mapping (`REFINE_EDGE`) has no field for `refineStrokes`, and `fields_to` only walks the fields it declares and silently ignores any others. So a step with Refine Edge Brush strokes was exported as a plain Select and Mask. Strict export reported no error and no skipped step, and playback after reimport gave a different selection.

## Fix
Select and Mask now exports through a dedicated `refine_edge_to` that returns no Photoshop equivalent when `refineStrokes` is non-empty. Strict export now returns an error for such a step, and `skipUnsupported` export lists it in `Skipped`. Steps with no strokes, an empty array or null still round-trip as before, and the existing pixel-target check is kept.

## Verified

## Not changed
No Photoshop descriptor encoding for Refine Edge Brush strokes is added, because no verified encoding exists. The import mapping and the other Select and Mask fields are unchanged.
