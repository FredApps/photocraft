## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Related to #5416.

Free Transform uploads document-color pixels directly while the surrounding canvas applies document-to-monitor conversion. On upstream, an AdobeRGB-compatible opaque sample changes from the canvas's #9C592D to #8C5933 when the transform preview appears. The actual drawn-texture regression fails on the wide-gamut case while its sRGB identity control passes: [baseline run](https://github.com/jonathanwxh-cell/photocraft/actions/runs/38549665214).

Apply the existing canvas display conversion to final preview uploads, including warp, covering layers and styled composites. Raw mip pixels remain available to effects. Display-profile cache keys prevent stale uploads, previous-profile textures are released, and native conversion runs in bounded parallel chunks. Selection tint and standalone mask/channel/path previews retain their diagnostic colors.

Verification on `d5e84c6` ([cloud run](https://github.com/jonathanwxh-cell/photocraft/actions/runs/38557574898)); the four submitted Rust files match that tested source exactly:

- Full UI crate: 2,801 tests passed, 14 ignored. Explicit offscreen rendering and the ignored release probe were also run and passed.
- Formatting, strict all-target UI Clippy, dependency layering and WASM passed.
- Regression coverage includes profile conversion, warp, covering layers, alpha preservation, selection tint, styled 16-bit previews, raw effect inputs and display-cache invalidation.
- Quick layout benchmark completed; cross-machine baseline comparison was skipped and quick mode does not enforce full-size budgets.
- Release 24 MP probe: first Display P3 preparation **512.461 ms**, identity sRGB **0.007 ms**; 1,000 cached P3 picks **9.287 microseconds**, with no new uploads. This measures CPU preparation, not GPU completion. Initial conversion remains noticeable at full resolution; cached dragging avoids repeating it. Earlier serial conversion measured 1,084.811 ms on a different runner, so no exact speedup ratio is claimed.
