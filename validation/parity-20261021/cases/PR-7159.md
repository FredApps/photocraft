### Problem
`cargo xtask i18n-coverage` reports Indonesian at 14 keys short of complete. Fourteen counted messages had no `@plural` entry, so with the Indonesian interface they appeared in English, for example:
- "Played 3 steps";
- "Imported 2 brushes from …";
- "Saved for Web: 5 files";
- the Layer Comps "layers recorded by this comp were deleted" warning;
- the Info panel's "{n} sample points removed".

The same keys are also missing from fr (covered by #4474), id, ko and zh-hans; pl is #7150. This PR is Indonesian only.

### Solution
`crates/ui-egui/src/i18n/id.tsv` adds the 14 `@plural` entries. Bahasa Indonesia has no plural forms (`plural_none`), so each entry has one form.

Wording reuses the terms the catalog already has: swatch, kuas, preset, slice, titik sampel, Smart Object tertaut, layer comp, Simpan untuk Web, peringatan, langkah. The entries were written from the meaning of the English text in ordinary vocabulary (clean-room, as the catalog header asks). Indonesian coverage is now 100%.

### Tests
`i18n::tests::indonesian_counted_messages_are_translated` checks three of the messages: a plain count, one with a `{group}` placeholder filled afterwards, and a noun-only count. It fails without the catalog entries, which fall back to English.
