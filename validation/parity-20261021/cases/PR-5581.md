## What



Photoshop's **Layer ▸ Group Layers** (Ctrl/⌘+G) and **Layer ▸ New ▸ Group from Layers…** create the new group collapsed (`▸ Group 1`), so the Layers panel shows one row in place of the grouped layers. PhotoCraft created it expanded.



- `layer.groupLayers` and `layer.new.groupFromLayers` (both `group_layers` in `crates/engine/src/layer_multi_cmds.rs`) now create the group with `expanded: false`.

- `Layer::group` still defaults to expanded, so New Group, PSD import and artboards are unchanged.



## Tests



- `group_from_layers_preserves_order` asserts that both commands create the group collapsed.

- Engine and ui-egui fixtures that walk group contents (`group_view_cmds`, `layer_nav_cmds`, `layer_tree_ui`, `layer_row_ui`, `shortcut_dispatch`) now open every group first with `layer.setExpanded {"all":true,"expanded":true}`. What they check is unchanged.

- `cargo test -p photocraft-engine --lib --tests` and `cargo test -p photocraft-ui-egui --lib --tests` pass. `cargo clippy -p photocraft-engine -p photocraft-ui-egui --all-targets -- -D warnings` is clean.

- Checked in the running desktop app over the control channel: grouping three selected layers shows a single collapsed `▸ Group 1` row above Background, and `document.inspect` reports `expanded: false`.
