Closes #7261.

The blend modes weren't missing. Every dropdown list (`widgets::dropdown_with` and `dropdown_with_tooltips`) was capped at 420 pt, which is 14 rows. In the Layers panel the list stopped at Overlay. Soft Light through Luminosity sat behind a thin scroll bar that's easy to miss.

### Change

- **List height:** the list grows to the visible window like a context menu, reusing `menu_scroll` (`min_scrolled_height`, which works around egui sizing a just-opened popup at 400 pt). It scrolls only when the window is too short.
- **List position:** the list opens under its box, or above it if only that fits. Otherwise it opens under the box and egui moves it up to fit the window.
- **Why not ComboBox:** `egui::ComboBox` has no setting for where the list opens. With the height lifted, egui put the list beside the box, the only place it fit, and moved it to the other side when a longer mode (Linear Dodge (Add)) widened the box, away from the pointer.
- **New `combo` helper:** it draws ComboBox's box itself (same look, same ids, same `ComboBox` accessibility info) and opens the list with `egui::Popup`. Because the ids match, `ComboBox::is_open`, `PressCombo` (press-drag-release) and the arrow keys keep working.

### Tests

- New: `the_open_blend_list_shows_every_mode`. With the list open, Normal through Luminosity are all painted and unclipped. The list stays in the box's column, and doesn't move as the box widens to Linear Dodge (Add). It fails without the fix: Soft Light is never painted.
- Updated: `wheel_steps_in_the_open_list_keep_the_chosen_mode_in_view` assumed the 420 pt list. It now runs in a 600 pt window, where the list still has to scroll, so it keeps testing that the wheel scrolls to the chosen mode.
- `cargo fmt`, `clippy -D warnings`, the ui-egui suite (3,192 tests), `cargo xtask wasm` and `cargo xtask layers` pass.

### Verified in the app

On macOS 27, Essentials workspace, Layers panel near the bottom of the dock: the open list shows all 27 modes, Normal to Luminosity, under the dropdown, moved up to fit the window.

Photoshop 2025 on macOS uses a native pop-up menu here: the checked mode sits over the button, the menu runs to the screen edge, and the rest scrolls behind a ⌄ arrow. It also puts separators between the mode groups. The reporter is on Windows, where Photoshop shows the whole list as a dropdown. This PR goes that way and leaves the separators for a follow-up.
