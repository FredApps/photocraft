### Summary of Changes
- Permitted clipboard actions (`"edit.copy" | "edit.cut" | "edit.paste" | "select.all"`) in `modal_allows()` within `crates/ui-egui/src/menus.rs`, preventing macOS AppKit from disabling Edit menu commands and swallowing `Cmd+C` / `Cmd+V` keystrokes when modal dialogs are active.
- Elevated `TextFieldMenu` rendering order to `Order::Tooltip` so right-click context menus are never obscured by modal dialog layers.
- In `crates/ui-egui/src/text_field_menu.rs`, enabled right-click Copy without prior text selection to automatically select and copy the entire field content.
- In `crates/ui-egui/src/color_picker_ui.rs`, allowed leading `#` to be pasted or typed and automatically stripped while preserving case and input responsiveness.
