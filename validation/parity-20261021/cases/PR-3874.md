### Summary
1. Fixes Blend If slider handle interaction: Alt-dragging a black or white triangle now splits it into two half-handles (`[min, max]`) for smooth feathered luminance blending, matching Photoshop 1:1.
2. Resolves heavy CPU spikes and stuttering during slider drag by throttling live Layer Style document preview compositing to ~30 FPS on the UI thread.

### Details
- **Alt-Split Triangle Handles:** Refactored slider drag math in `blend_if_bar` (`layer_style.rs`). Alt-dragging the black triangle splits the right half (`[0, max]`); Alt-dragging the white triangle splits the left half (`[min, 255]`). Dragging halves back together seamlessly reunites them. Handle ordering `0 <= black_lo <= black_hi <= white_lo <= white_hi <= 255` is strictly maintained.
- **Live Preview CPU Throttling:** In `canvas.rs`, dragging sliders previously triggered full synchronous CPU composite passes on every pointer move event (up to 120+ times/sec), pegging CPU cores at 100%. Live Layer Style preview rendering is now throttled to ~30 FPS (>= 33ms) during rapid drag gestures, while guaranteeing the final state is always rendered immediately upon release or timer trigger.
