## Pinned upstream reproduction and regression specification

Closes #1714.

**Filter › Other › Frequency Separation…** sets up frequency separation in one step, instead of the duplicate / Gaussian Blur / Apply Image / blend mode routine.

From the active pixel layer it adds a **Frequency Separation** group right above it, holding:

- **Low Frequency** (Normal): the layer through Gaussian Blur at the chosen radius. These are the same pixels Filter › Blur › Gaussian Blur produces.
- **High Frequency** (Linear Light): `High = (Source − Low) / 2 + ½` in each colour channel, keeping the source's transparency.

This is Photoshop's recipe: Apply Image › Subtract, Scale 2, Offset 128 in 8-bit, and Add + Invert, Scale 2, Offset 0 in 16-bit, which give the same values. Linear Light computes `Low + 2·High − 1`, so the result is the source again. In 32-bit our Linear Light uses the same formula, so the recipe is unchanged there. The source layer itself is not modified, it is one history step, and the High layer ends up targeted, ready for healing.

The command is `layer.frequencySeparation` with `{"radius": 0.1..1000 = 4}`. From the menu it opens the existing schema dialog, which has a single Radius field. Photoshop has no menu item for this (people record it as an action), so the id is our own. The menu entry goes after Color to Alpha (`PLACE_AFTER`). I kept it out of `filter.*` because it adds layers rather than filtering the target, so mask/channel routing, Fade and Last Filter would all be wrong for it. The menu label is in all 17 catalogs, which the coverage test requires.

**Limits**

- Only RGB and Grayscale. In CMYK and Lab the compositor does not blend on the stored values (in a test the rebuild was off by 0.7 and 0.14), so the command is refused there rather than giving a wrong split.
- Linear Light clips to 0..1, so 32-bit values above 1 come back as 1.
- 8-bit stores High to the nearest level, so the rebuild is within ±1 level, the same as Photoshop's recipe.
- The new layers carry only the source's pixels (no mask, style, opacity or blending options), and the selection is ignored. The rebuild is exact for an opaque, Normal, 100% layer, which is the normal case for this technique.
- It is refused, with a message, on non-pixel layers (type, shape, adjustment, group, smart object), on empty layers, and when a channel, Quick Mask or layer mask is targeted.
