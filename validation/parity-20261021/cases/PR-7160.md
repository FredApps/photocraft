### Problem
`cargo xtask i18n-coverage` reports Korean at 14 keys short of complete. Fourteen counted messages had no `@plural` entry, so with the Korean interface they appeared in English, for example:
- "Played 3 steps";
- "Imported 2 brushes from …";
- "Saved for Web: 5 files";
- the Layer Comps "layers recorded by this comp were deleted" warning;
- the Info panel's "{n} sample points removed".

The same keys are also missing from fr (covered by #4474), id, ko and zh-hans; pl is #7150. This PR is Korean only.

### Solution
`crates/ui-egui/src/i18n/ko.tsv` adds the 14 `@plural` entries. Korean has no plural forms (`plural_none`), so each entry has one form, with the counter 개 as the catalog's other counted messages use.

Wording reuses the terms the catalog already has: 색상 견본, 브러시, 사전 설정, 분할 영역, 샘플 지점, 스마트 오브젝트, 레이어 구성 요소, 웹용으로 저장, 경고, 단계; imperatives end in -하세요 as elsewhere in the catalog. The entries were written from the meaning of the English text in ordinary vocabulary (clean-room, as the catalog header asks). Korean coverage is now 100%.

### Tests
`i18n::tests::korean_counted_messages_are_translated` checks three of the messages: a plain count, one with a `{group}` placeholder filled afterwards, and a noun-only count. It fails without the catalog entries, which fall back to English.
