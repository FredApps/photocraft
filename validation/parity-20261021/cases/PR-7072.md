Fixes #7031

Reopening Layer Style on a layer whose gradient overlay has more than two stops (classic interpolation or a PSD import bakes interior stops) reset the From/To fields to the factory black-to-white, because `values_of` only loaded endpoint colours and geometry for plain two-stop gradients.

Now the dialog always loads the first and last stop colours plus reverse, style, angle and scale. Interior stops stay in the effect snapshot, so applying the dialog again keeps the baked curve and only retints the ends.

Test: `baked_gradient_overlay_keeps_endpoint_colours_on_reopen` in `crates/ui-egui/src/layer_style.rs` applies a classic red-to-blue overlay, reopens the dialog, checks From/To are still red/blue, and re-applies to confirm the multi-stop curve and endpoints survive.
