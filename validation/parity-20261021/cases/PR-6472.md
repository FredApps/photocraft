## Summary

Changing a selected shape's stroke width through **4 px → 0 px → 4 px** currently discards its paint and style. Keep the existing stroke in the document and update only its width in both the options bar and Properties:

```diff
- 0 px → remove the stroke → rebuild from defaults
+ 0 px → retain the stroke → restore the original style when width increases
```

- Preserve color/alpha, opacity, alignment, caps, joins, miter limit and dash settings, including a native save/reopen at zero width.
- Keep explicit **No Color** removal and deliberate 3 px activation from color/style choices. Opening or dismissing Stroke Options alone does not enable a zero-width stroke.
- Use the existing Properties gesture convention for options-bar undo keys: one history step per drag, with separate numeric edits undoable independently.

Related: #6259. This alternative retains the original `ShapeStroke` in the document model and covers both width controls, rather than reconstructing a removed stroke from tool defaults.
