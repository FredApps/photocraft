## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Fixes #4919.

The control channel applied the existing modal-dialog guard to `ui.menu.invoke` but bypassed it for `engine.execute`. Consequently, automation could change a document while an adjustment dialog still displayed its original state.

Apply the same modal-availability policy to both command entry points.

Keep the existing Camera Raw continuation exception, which operates on its active dialog rather than issuing an unrelated document command.

Added a regression test that:
- Opens a Hue/Saturation dialog.
- Rejects Invert through both command entry points.
- Confirms the document revision and dialog fields remain unchanged.
- Verifies the command succeeds after the dialog is cancelled.

Tests added but not executed locally.
