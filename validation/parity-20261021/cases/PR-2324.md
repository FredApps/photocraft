## Summary

Addresses #2301.

Extend PhotoCraft's existing toolbar flyout interaction
to support dragging from a grouped tool button into its
flyout and releasing over the desired tool.

## Problem

Grouped tools already support right-click and long-press
flyouts.

However, dragging away from the original button does not
provide the complete Photoshop-style press-drag-release
selection workflow.

## Changes

- Detect dragging away from a grouped tool button.
- Open the corresponding tool flyout during that gesture.
- Allow releasing the primary pointer over a flyout item
  to select that tool.
- Prevent the original toolbar button from activating
  after the flyout gesture.
- Preserve existing right-click and long-press behavior.
- Add regression tests for drag opening and release targets.

## Expected Behavior

1. Press a grouped toolbar tool.
2. Drag away from the button.
3. The grouped tool flyout appears.
4. Move over another tool.
5. Release to select that tool.
