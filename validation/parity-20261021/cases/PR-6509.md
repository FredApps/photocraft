Closes #6483.

The issue lists two symptoms, but they have one cause. While a type edit is open, the Type tool treats every key without ⌘/Ctrl as typing (Photoshop does the same). The edit never ended when you selected another layer, so tool shortcuts like V typed a letter instead. Once the edit ends, the shortcuts work again.

The reporter's build is 0.9.0. #5612 fixed the Layers-panel row click, but it merged a few hours after the `v0.9.0` tag. That fix covered only the row click: every other way of selecting a layer still left the edit open.

## Changes

1. **The edit ends when you move on.** `type_tool::end_if_left` runs every frame, next to the existing check that commits when you switch tools, and at the top of `handle_keys`. It commits the edit once its layer isn't the active layer, or its document isn't the active document. That covers:
   - layer and smart-object menu picks
   - the canvas layer picker
   - Select ▸ Deselect Layers
   - automation and MCP `layer.select`
   - document tabs
   - File ▸ New / Open
2. **Typing can no longer reach the wrong document.** `TextEdit` used to store only a layer id. `.pcraft` files keep their saved layer ids, so opening one file twice gives two documents with matching ids. After switching tabs, typing went into the other document's layer with the same id: a test saw `"Bee"` become `"BeZe"`. `TextEdit` now records its document (`document: Option<u64>`, serde default):
   - `commit_with` commits in that document, in its own history.
   - If that document has been closed, the edit is dropped without running anything.
   - `draw_overlay` draws nothing for an edit that belongs to another document.
3. **The layer you picked stays selected** (from review). Ending an empty Type Mask undoes its session, and the undo also restored the selection from before it. So the layer you had just picked (or Deselect Layers) was reversed. `end_if_left` now puts your selection back through a new `Session::restore_layer_selection`. That call drops layers that no longer exist and refuses an active layer that no longer exists. It isn't an edit, so a saved document stays saved.

The early commit from #5612 in `panels.rs` stays. It's still needed when you click the row of the layer you're already editing, because then the active layer doesn't change.
