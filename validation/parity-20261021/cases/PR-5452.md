## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Preparation for splitting #3446 into reviewable parts. These are moves and signature changes only, with no behaviour change, so the later feature PRs show only the new code:

- The Shape tools' options bar body moves from `vector_ui.rs` into a new `shape_options.rs`, and the fill/stroke swatch with its colour helpers moves into a new `shape_paint_ui.rs`. The code is unchanged; `vector_ui` keeps the mode dropdown and calls `shape_options::options_bar`.
- The gradient stop strip no longer reaches into the app: it returns a `StopAction` (preview, commit, edit colour) and the gradient panel / preset editor run the same commands as before.
- The pattern library grid is pulled out of `pattern_picker` as `pattern_grid`, so another popup can show it inline.
- `move_ui::shown_offset` is renamed to `shown_layer_offset`.

Existing tests pass unchanged (two test imports follow the moved helpers). No UI change, so no screenshots.
