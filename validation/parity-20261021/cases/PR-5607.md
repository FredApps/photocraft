## Pinned upstream reproduction and regression specification

Fixes part of #5599 (finding 2: PSB long-key length bug in the TIFF writer).

When a large-document (PSB) TIFF was saved back as little-endian, `crates/psd/src/tiff.rs` checked the byte-reversed key to decide the length size. The reversed key never matches the list of keys that get 8-byte lengths, so the length was read as 4 bytes and every block after it was corrupted. It now uses the key as stored, the same way the block writer does.

- Adds regression test `psb_foreign_order_long_key_block_keeps_its_8_byte_length`.
- `cargo test` and `cargo clippy -D warnings` pass for `photocraft-psd`.
