## Summary
On macOS, when PhotoCraft runs from its app bundle, the Dock icon switched from the bundle's icon to a monochrome glyph once the window opened (#7253). We skipped `with_icon` inside a bundle so the bundle's `.icns` would be used (#5849), but leaving the icon unset let eframe substitute its own default icon. The viewport now passes an empty `IconData` in that case, so eframe doesn't set a runtime icon and the bundle icon stays in the Dock.

## What changed
- `apps/photocraft/src/app_icon.rs`: new `viewport_icon`, which returns `window_icon()` when a runtime icon should be set and `IconData::default()` otherwise.
- `apps/photocraft/src/main.rs`: `native_options` always calls `with_icon(app_icon::viewport_icon(...))`.
- New unit test `viewport_icon_blocks_eframe_default_when_runtime_icon_is_skipped`.

## Testing
