Fixes #7785.



In Photoshop, when airbrush-style build-up is on, the number keys set the brush's Flow and Shift+number sets its Opacity. PhotoCraft always set Opacity.



`opacity_keys::apply` now swaps the two roles for the Brush and the Eraser while the brush's `build_up` is on. Nothing changes for:

- the Pencil, which has no Flow;

- the Eraser in Pencil or Block mode, which has no build-up (its options bar already disables Flow and the airbrush button for those modes), so digits still set Opacity there;

- every other tool (layer opacity/fill, Gradient/Paint Bucket opacity).



Two-digit entry (4 then 5 = 45%) and the 1% Flow floor work as before. The module doc and the shortcut row in `docs/brush-parity.md` mention the swap.



Test: `with_build_up_digits_set_flow_and_shift_digits_set_opacity` covers the Brush with build-up (digit sets Flow, Shift+digit sets Opacity), the Pencil (unchanged), the Eraser in Brush mode (swapped) and in Pencil mode (not swapped). It fails on main, where the plain digit sets Opacity.
