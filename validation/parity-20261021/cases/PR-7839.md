## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Part of #7807 (the error text can't be copied). Independent of #7837 and #7838.

A refused Free Transform's message lands in a notice over the canvas. Dragging across it does select the text, but outside a text field ⌘C/Ctrl+C is turned into Edit › Copy, so the layer was copied and the message never was. While text is selected in a label (dragged across, double-, triple- or shift-clicked), a plain ⌘C now copies that text. ⌘X and ⌘V stay the document's, and after a plain click on a label ⌘C still copies the layer.
