## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Fixes storytold/PhotoCraft#5745 (the all-black mask). Narrowed per review; the other behaviour changes are now #7395, #7396 and #7397.

**Cause:** in `panorama::seam_labels`, an image whose coverage lies wholly over the earlier images (`nn == no`) was skipped, so the earlier images kept every cell. In #5745, Auto-Align moves the second photo partly off the canvas. Cropped to the canvas, it's all overlap, so it got an all-black mask and the picture didn't change.

**Fix:** for such an image, its side of the seam is the one it lies towards from the composite's centre. An image centred on the composite (or covering the same cells) has no side and is still skipped, as before.

**Tests:**
- `panorama::tests::an_image_wholly_inside_the_composite_still_gets_its_side` (algo): the right-hand image gets one run on its side; the centred and same-cells cases keep the old result.
- `align_cmds::tests::auto_blend_panorama_of_a_layer_the_canvas_crops_to_all_overlap` (engine): the top layer hangs off the canvas and now shows on its side within the canvas.
- `cargo test -p photocraft-algo --lib an_image_wholly_inside` and `cargo test -p photocraft-engine --lib align_cmds::tests::auto_blend`: all pass.
