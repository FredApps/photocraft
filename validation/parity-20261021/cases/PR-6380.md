## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Pen tilt and barrel rotation changed the painted brush orientation while its cursor kept the static tip orientation. Apply the shared paint angle controller and pose overrides to the cached outline before the canvas view transform, and show Brush Projection foreshortening.

Fixes #5428. Addresses the pen-orientation example in #6350. This does not preview every pressure, jitter or stroke-direction dynamic.

Verified source: 6b9fc995 on upstream 2b3d0563.

- [Baseline regression](https://github.com/jonathanwxh-cell/photocraft/actions/runs/38817773811): simulated pen tilt leaves the old native cursor bitmap unchanged; the workflow requires that exact assertion failure.
- [Candidate cloud verification](https://github.com/jonathanwxh-cell/photocraft/actions/runs/38821241859): full UI library 2,960 passed, 0 failed, 14 ignored, plus UI integration tests; formatting, strict UI Clippy, layers and WASM passed. Focused cursor tests overlap the full suite and are not added to its count. Software Vulkan was required.
- Cursor tests compare rotation against both an emitted dab angle and a static 90-degree cursor reference, and cover projection, mouse/disabled dynamics, pose overrides, view transforms and outline-cache reuse. Inspected all six exported cursor PNGs: tilt/barrel rotation turn the flattened tip, and projection foreshortens the round tip.
- Release component probe, five samples of 360 updates: changing rotation took 61.7–62.7 microseconds/update; cached static cursor took 0.44–0.47 microseconds after its first 2.32-microsecond sample. This measures cursor generation, not physical tablet or end-to-end latency; it is added work, not a speedup.

The earlier verification attempt lacked a graphics adapter and failed five UI tests. The linked complete run installs Mesa, requires Vulkan, and passes those tests. No production change was needed for that environment failure.
