Fixes #5363.

Ctrl + scrollwheel zoomed in 0.5.0 and panned sideways in 0.8.2 because egui treated COMMAND as a horizontal-scroll modifier. Ctrl/Cmd + a notched wheel zooms ×1.1 around the pointer again. Shift still pans sideways. Fractional Ctrl+wheel from a precision touchpad remains a pinch.
