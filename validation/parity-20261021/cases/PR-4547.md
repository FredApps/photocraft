Fixes #4478

PhotoCraft's icon appeared more square than FilmCraft and other apps because `packaging/icons.sh` cropped 22 units off each side, cutting away most of the rounded corners.

**Solution:**
Render the full 512-unit tile like other Craft apps (no crop), matching the `rx=112` radius in the SVG.

**Changes:**
- `packaging/icons.sh`: Removed Windows/Linux crop (was 468x468, now 512x512)
- Regenerated all hicolor PNGs and `.ico`
- Updated `assets/app-icon/README.md` with new dimensions
- Added corner radius check to `apps/photocraft/src/app_icon.rs`

**Verification:**
Corner transparency now matches FilmCraft:
- 256px: 16 transparent pixels (was 6)
- 512px: 33 transparent pixels (was 12)
- .ico 256: 16 transparent pixels (was 0)

**Testing:**
- New test fails if corners are cropped again
- All app_icon tests pass
