Fixes #7786

### Problem
Create Rectangle / Ellipse / Triangle / Polygon (a single click with a Shape tool) showed Width and Height only in the ruler unit (Preferences › Units & Rulers), which is pixels by default. There was no way to switch them to mm or inches in the dialog. In Photoshop, a right-click on these fields picks their unit, as the reporter showed.

### Solution
`crates/ui-egui/src/shape_dialog.rs`:
- **Unit menu:** a right-click on Width or Height opens the length-units menu that the rulers and Free Transform's W and H fields already use (`rulers::unit_menu`). Pixels, Inches, Centimeters, Millimeters, Points, Picas and Percent are listed, with the current one checked.
- **Display:** the picked unit becomes the dialog's `unit`, and both fields show the size in it, converted at the document's resolution.
- **Storage:** the sizes are still stored in pixels, so `shape.create` and automation (`ui.dialog.set`) are unchanged.
- **Default:** the dialog opens in the ruler unit, as before.
- **Remembered:** OK keeps the unit along with the other values, per tool. A remembered value that isn't a unit is ignored.

Typing a unit in the field ("50 mm") already converted before this; the menu changes what the fields display.

### Tests
`shape_dialog_tests::width_and_height_show_in_the_picked_unit_and_remember_it`:
- A rectangle click opens the dialog with `unit` = the ruler unit, and Width and Height read "100 px".
- With Millimeters picked, they read "35.28 mm" (100 px at 72 ppi), and the stored width is still 100 px.
- OK with 50 px in mm, then the next Create Rectangle opens in mm with width 50.
- A remembered unit that isn't one (`furlongs`) opens in the ruler unit.

It fails without the change: the dialog has no `unit`.
