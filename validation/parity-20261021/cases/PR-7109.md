## What changed

`a_damaged_preset_set_keeps_the_other_sets` (#5602) checks that one damaged preset set in the preferences file does not discard the others at the next launch. It left out `export_presets`, which #5344 added and #6906 put back into `load_presets_json`, and `recent_documents`. The test now saves an Export As preset and checks that it survives each damaged set, `recent_documents` included. It also damages `export_presets` and `documents` on their own, and gives a null set beside the Export As presets.

The test is @brandongunderson's, from #6479, copied unchanged so the two pull requests make the same change to `crates/engine/src/presets/tests.rs` and merge without a conflict. No code outside the test changes.
