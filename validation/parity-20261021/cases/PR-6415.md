Save for Web: set the export's Width and Height (linked in proportion), Percent and the resampling method.

In Photoshop, Save for Web's Image Size has Width and Height linked by a chain, a Percent field and a Quality menu for the resampling method. Before this PR, PhotoCraft only had Percent plus a read-only "W: H:" line. The export command already accepted `width`, `height`, `percent` and `resample`, so this change is only in the dialog. A typed width or height sets the other side from the document's aspect while Constrain proportions is on (the default each time the dialog opens). Percent sets both sides. Turning Constrain proportions back on sets the height again from the width in the document's proportions. Resample offers Photoshop's list: Nearest Neighbor, Bilinear, Bicubic, Bicubic Smoother, Bicubic Sharper. It defaults to Bicubic, the engine's current default. I labelled it "Resample" rather than "Quality" so it doesn't clash with the JPEG Quality field. Happy to switch both the default and the label. As #1857 decided, each opening starts at the document's full size; the resample method is remembered with the other encoding choices. When the preview proxy is full size (2048 px or less), it now uses the chosen method, so the preview, colour table and size estimate show it. The document itself is never resized. The size helpers are reused from Export As (`resize_from_side`, `resize_from_scale`).

Part of #6388: this covers point 1 only. Dropping "Legacy" from the name and adding new formats stay out. Possible follow-ups in the engine, untouched here: `file.export.saveForWebLegacy` passes any `resample` through to Image Size, and `"none"` exports without resizing. The `.atn` mapping also doesn't read Save for Web's resize.

Validation:

Unlinked, a height of 50 stays; linked again, it goes back to 40. The file comes out at 60 × 40, and the document's revision and size are unchanged.
- `save_for_web_reopens_at_full_size_with_the_resample_method`: fails on main (no Width field), passes here. Reopened on a 240 × 160 document, the dialog is back at 240 × 160 and keeps `nearest`.
