**TL;DR:** With a ratio preset (e.g. 16:9), X now turns the crop frame to 9:16 at the same size instead of shrinking it, and X again brings it back.

Fixes #7057.

## What was wrong
`swap_orientation` (`crates/ui-egui/src/crop_ui.rs`) swapped the preset ratio and then fitted it inside the old, unswapped frame. Fitting never adds area, so every X shrank the frame: a centred 80x45 frame became 25.3x45, then 25.3x14.2 after a second X. Without a preset, X already turned the frame.

## Fix
The frame turns first (`keyed(app, swapped(r))`), then `apply_ratio` fits the swapped ratio to it (a no-op for a frame that already matches).

## Test
`x_swaps_the_frame_orientation_not_the_colours` extended: 16:9, frame [60,27.5,140,72.5]; X → 9:16 and [77.5,10,122.5,90]; X again → 16:9 and the original frame. It fails on main.
