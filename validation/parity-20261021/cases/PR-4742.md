Addresses #4714.

The macOS package builds photocraft-cli but only includes it in the separate CLI download. Generated droplet scripts therefore fail when PhotoCraft is installed without that download.

This change bundles and signs photocraft-cli inside PhotoCraft.app. Generated droplet scripts now check PHOTOCRAFT_CLI first, then common application installation paths, and finally PATH.

Updated the shim assertions and macOS packaging documentation.

macOS packaging and notarization have not been tested locally. Native Finder drag-and-drop support remains outside this change.
