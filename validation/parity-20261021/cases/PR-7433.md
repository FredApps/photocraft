### What



Photoshop keeps the **Warp Text** button in the Type tool's options bar; PhotoCraft only had it in the Type menu and the text context menu. This adds it to the options bar, right after the text colour swatch.



### Behaviour



- Opens the existing **Warp Text…** dialog (`type.warpText`), which already starts from the layer's current warp.

- Drawn **pressed** while the shown type layer has a warp.

- **Disabled** when no type layer is targeted.

- Reuses the existing translated "Warp Text…" string — no new i18n keys.



### Icon



The glyph is based on Lucide's `type` icon (the same artwork as the Type tool's `type.svg`), sheared with a shallow arc added; it is themed with `currentColor` and drawn at 15 px inside the 24 px button. `ATTRIBUTION.md` lists it as a derivative under Lucide's ISC notice.



### Testing



- New options-bar UI test: the icon is embedded, the button opens the Warp Text dialog, and the pressed state follows the layer's warp.

- `cargo test -p photocraft-ui-egui --lib warp` — green

- `cargo fmt --check`, `cargo clippy -p photocraft-ui-egui --all-targets -- -D warnings` — clean

- Manually checked in a dev build (button placement, pressed state, dialog).
