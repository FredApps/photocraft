## What changed
The Move tool options bar showed only three align buttons (left edges, horizontal centers, right edges) with unrelated placeholder icons, and the "…" menu listed plain text. Now:
- all six Align buttons (left, horizontal centers, right, top, vertical centers, bottom) with dedicated icons and "Align: <name>" tooltips;
- the "…" menu lists Align and Distribute (all 8 commands) with the same icons next to their names;
- buttons dispatch the existing `layer.align.*` / `layer.distribute.*` commands and stay enabled by the commands' own rules (selection count).
- 14 original SVG glyphs (`assets/icons/align-edge-*`, `distribute-*`), attributed in ATTRIBUTION.md. No new translatable strings: tooltips are built from the already translated "Align" and the menu labels.

## Root cause
The bar only wired three of the six align commands and reused generic Lucide panel icons.
