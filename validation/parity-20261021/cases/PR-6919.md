Fixes #6865.

Using the marquee, lasso, Magic Wand, Quick Selection, Object Selection or any Select menu command no longer marks a clean document as modified. You don't get a title-bar asterisk or a save prompt on close just for selecting.

**How**
- `Session::edit`, `undo`, `redo` and `history.selectState` keep a clean document clean when the step changed nothing but `Document::selection` (`DocState::keeps_clean` / `bump_revision`). Making a selection is still a history step, so undo and the History panel work the same as before.
- `layer_multi_cmds::selection_only_change` decides what counts as selection-only. It uses `same_pixels` to compare pixels by tile pointer, which also turns down video layers. Every other field is compared structurally, and `Arc`-of-`Eq` data shortcuts on pointer identity, so the check stays cheap on big documents. The destructure is exhaustive, so a new `Document` field won't compile until someone decides whether it counts.
- A real edit still dirties the document, and a later selection change or undo can't make it clean again. Save Selection (adds a channel) and Quick Mask also still dirty it.

**Tests**
- New `tests::selection_tools_do_not_dirty_the_document`, at 8, 16 and 32-bit: rect, ellipse add, lasso subtract, inverse, all, deselect, then undo/redo, a history jump, and a real edit afterwards.
- Ran `cargo test -p photocraft-engine --lib` filtered to `dirty|clean|save|undo|history_select|selecting_a_layer|edits_that_change_no_pixels`: 111 passed.
