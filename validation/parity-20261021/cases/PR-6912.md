## Cause

`normalize_shortcut` (`crates/engine/src/prefs.rs`) title-cases every named key. So a binding set to `Shift+PageUp` in Edit › Keyboard Shortcuts was saved as `Shift+Pageup`, and egui's case-sensitive `Key::from_name` matches no key with that spelling: the shortcut never fired.

This affected every command, not just Flip. The reporter's other PgUp/PgDn shortcuts worked because built-in defaults keep the right spelling. The other keys affected are the ones egui spells with several capitals: OpenBracket, CloseBracket, OpenCurlyBracket, CloseCurlyBracket, BrowserBack and IntlBackslash. Arrows are named `Up` etc., so they were fine.

## Change

- **`normalize_shortcut` (via `capitalize`):** multi-word key names keep egui's spelling.
- **`shortcuts::parse`:** matches key names case-insensitively, so bindings already saved as `Pageup` by earlier versions work without re-binding.

## Tests

- **`layer_shortcut_tests::custom_page_up_and_page_down_bindings_fire`:** binds Shift+PageUp, Ctrl+Shift+PageUp and Ctrl+Alt+PageDown to `edit.transform.flipHorizontal`; each press runs it. Without the change, nothing runs (`left: []`). The test also checks that `Shift+Pageup` parses.
- **`prefs::tests::shortcuts_normalise_and_detect_conflicts`:** `shift+pageup` → `Shift+PageUp`, `Ctrl+Alt+PAGEDOWN` → `Ctrl+Alt+PageDown`, `Cmd+openbracket` → `Cmd+OpenBracket`.
