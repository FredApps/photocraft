# Sticky Search Field in Font Picker



## Description

Fixed the font selection dropdown search field to stay pinned at the top of the font list viewport while browsing through fonts, matching Photoshop's expected behavior.



## Changes Made



### `crates/ui-egui/src/type_tool.rs`

- Modified the `family_picker_in` function to wrap font rows in `egui::ScrollArea::vertical()`

- The search field remains fixed at the top of the popup while only the font list scrolls underneath

- This ensures the search field is always visible and usable when browsing long font lists



## Behavior Changes



**Before:**

- Scrolling the font list moved the search field out of view

- Search field became unusable when the list exceeded viewport height



**After:**

- ✅ Search field remains fixed at the top of the font list viewport

- ✅ Only the font list itself scrolls underneath

- ✅ Search continues to filter the list correctly while the field stays in view

- ✅ All existing interactions (click, hover, arrow keys, wheel) continue to work
