### Summary
Implements Photoshop's standard 3x3 reference point pin widget (Reference Point Location) in the Free Transform options bar.

### Features
- 3x3 interactive pin selector in the options bar for pinning transformation pivot to any corner, edge center, or the midpoint.
- Projective homography pivot snapping (`h.apply(u, v)`) ensuring the pivot remains geometrically accurate across perspective, skew, and scaling transforms.
