## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

A ZIP archive comment can contain bytes matching the end-of-central-directory signature. The backward scan can mistake them for the directory record and hide valid entries.

- Accept a candidate only when its declared comment ends at the archive boundary and the supported central directory ends at that record.
- Use checked arithmetic when validating candidate positions.

Regression coverage: Regression tests cover false signatures inside comments, empty through maximum-length comments, central-directory digital signatures, and truncated comments.

Scope: The existing non-ZIP64 reader only; no new archive format support.
