### Summary of Changes
- In `crates/engine/src/retouch_cmds.rs`, decoupled the blur tool sigma calculation from sharpen: blur sigma now scales with brush size `(stroke.brush.size * 0.15).clamp(1.0, 64.0)` instead of `(stroke.brush.size * 0.03).clamp(1.0, 4.0)`, ensuring visible, perceptually expected blur changes at standard 8-bit quantization.
- Added regression unit test `blur_scales_with_brush_size_and_diffuses_pixels_visibly` in `crates/engine/src/retouch_cmds/tests.rs` verifying pixel diffusion across step edges for 8-bit and 16-bit depths at brush sizes 20 and 60.
