Fixes #8093



### Problem

Photoshop stores a layer's state per layer comp in `cmls.layerSettings`, and writes `enab` (visibility) only where it **changes** from one comp to the next. An entry without `enab` has the last `enab` before it, or is visible when none came before.



PhotoCraft read a missing `enab` as "this comp leaves the layer as it is". So on a fresh open, Layer Comps › Apply could show layers Photoshop hides, or hide layers it shows. The reporter's two files:



| File | Comp | Photoshop | PhotoCraft before |

|---|---|---|---|

| repro_comp_new_layer.psd (C: `[c1 {}], [0 {enab false}]`) | c1 | C visible | C hidden |

| repro_comp_inherit.psd (A: `[c1 {}], [c2 {enab false}], [c3 {}], [0 {}]`) | c3 | A hidden | A visible |



In real character PSDs with ~10 comps, the result was whole groups on or off, and composites up to 211 levels off.



### Solution

`crates/io/src/comps_map.rs`, `decode_comps`, for each layer's `layerSettings`:

- **Order:** the entries are walked in order, keeping the last `enab` seen.

- **Real comps:** an entry for a real comp gets its own `enab` or the inherited one, starting from visible. So every comp the layer has an entry for now records a visibility, and `layerComp.apply` (which honours each comp's Visibility option) shows what Photoshop shows.

- **Last Document State:** the entry for comp 0 keeps exactly what it records, as before. Our own writer emits that entry without `enab` when a document has no Last Document State, and inheriting there would invent one on the next open.



Positions are read as before. A comp whose Visibility option is off still doesn't apply visibility.



`crates/io/tests/comps_artboards.rs`: the synthetic round trip has a comp that records nothing for one layer. A PSD can't say "leaves it alone": that entry has no `enab`, which Photoshop reads as the previous comp's visibility, and so does the import now. The test's expectation says so.



### Tests

`comps_map::tests::a_comp_entry_without_enab_inherits_the_previous_visibility` builds both of the reporter's layers' `cmls` with the same entries:

- A is visible in c1, hidden in c2, and hidden in c3 (inherited);

- C is visible in c1 (no `enab` before it);

- the Last Document State keeps C hidden and records nothing for A.



It fails without the change: those comps had no visibility, so applying them left the layers as they were.
