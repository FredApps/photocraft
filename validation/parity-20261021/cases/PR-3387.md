## Summary

Add lossless JPEG XL (.jxl) export to PhotoCraft using the
pure-Rust zune-jpegxl encoder.

## Changes

- Add JPEG XL format identification, MIME type and extension.
- Implement lossless 8-bit and 16-bit JPEG XL encoding.
- Support grayscale, grayscale+alpha, RGB and RGBA images.
- Integrate JPEG XL into Save As and Export As.
- Support .jxl through the existing flat-image export pipeline.
- Preserve appropriate color conversion and fidelity warnings.
- Handle encoder failures without crashing the application.
- Document capabilities and limitations.

## Tests

Added regression tests covering:

- JPEG XL signature detection
- Format capabilities and extension recognition
- Deterministic encoding
- Float-to-integer conversion
- 8/16-bit lossless output verification using jxl-oxide
- Grayscale, grayscale+alpha, RGB and RGBA
- Graceful handling of unsupported dimensions

## Limitations

- Export is currently lossless only.
- The encoder writes bare JPEG XL codestreams without embedded
  ICC, EXIF, XMP or DPI metadata.
- JPEG XL import remains separate and is being reviewed in #2868.
