## Pinned upstream reproduction and regression specification

Fixes #7502, fixes #7512, fixes #7513, fixes #7514, fixes #7503, fixes #7506, fixes #7507, fixes #7196, fixes #7236, fixes #7246, fixes #7287.

Strict `.atn` export succeeded on these steps but wrote descriptors that can't carry one of their options, so the imported step replayed differently. The tickets ask for the option to be kept, or for strict conversion to be refused. Neither the exporter nor the importer maps these options today. Writing them would mean inventing Photoshop descriptor keys that can't be checked offline, so this change refuses them. Strict export now fails with the step named, as for any step without a Photoshop equivalent, and an export with `skipUnsupported` lists it as skipped. Steps without those options export exactly as before.

| Command | Refused when | Tickets |
|---|---|---|
| `layer.new.layer` | `clipToPrevious`, a `color` label, `fillNeutral`, or `position: "below"` (non-default values) | #7502, #7512, #7513, #7514 |
| `file.new` | `background` is `black` or a hex colour, or `backgroundColor` is given (`Fl  ` holds only white, transparent or Photoshop's own background colour) | #7503 |
| `select.loadSelection` | `invert`, or `operation` other than `new` | #7506 |
| `layer.newFillLayer.solidColor` | a `color` the opaque RGB descriptor can't hold (alpha, or unparseable) instead of silently exporting no colour | #7507 |
| `layer.setProps` (and its rename and label twins) | any key other than `layer`, `name`, `opacity`, `fill`, `blend`, `visible`, `color` (`locked`, `locks`, `clipped`, `channels`, an explicit `layers` list) | #7196, #7246 |
| `layer.groupLayers` | an explicit `layer` (the descriptor always groups the selection) | #7236 |
| Any mapped 32-bit integer field (e.g. Add Noise `seed` → `FlRs`) | a value outside `i32`, which was clamped to `i32::MAX`/`MIN` (seeds above 2147483647 replayed as 2147483647) | #7287 |

Mapping any of these options properly later only needs the matching import and export keys, and a test showing the round trip.
