### Summary of Changes
In Photoshop, the **New Guide Layout** dialog (`View > Guides > New Guide Layout…`) displays its spacing, margin, and size fields formatted in the document's active ruler unit. Users can type any unit (`cm`, `in`, `px`, `pt`, `mm`, `pica`, `%`) or bare numbers without them being forced or immediately converted to pixels while typing.

This PR brings PhotoCraft's New Guide Layout into 1:1 Photoshop parity:
1. **Ruler unit formatting on open**: When the dialog opens or resets, fields (`gutter`, `rowGutter`, `width`, `height`, `margin`) format in the document's active ruler unit (`"0.71 cm"`, `"0.28 in"`, `"20 px"`).
2. **Support arbitrary units**: Singleline text edits replace the fixed `"px"` `value_field` widgets so users can type any supported unit or bare numbers without immediate conversion.
3. **Normalization on lost focus**:
   - Bare numbers append the document's active ruler unit (e.g. typing `10` -> `10 cm` when ruler is `cm`).
   - Unspaced unit entries format with a space (e.g. typing `10cm` -> `10 cm`, `2in` -> `2 in`, `20px` -> `20 px`).
4. **Tab vs Mouse Click selection**:
   - Tabbing into a field selects all text so typing immediately replaces it.
   - Clicking with the mouse places the caret at the clicked point without selecting all text.
5. **Live canvas preview**: Typed units are converted with document DPI/extent for instant preview and command execution.
6. **Reopening conversion**: Closing/confirming and reopening after changing the document's ruler unit converts the stored values to the new ruler unit.
