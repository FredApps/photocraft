Fixes #3176

Launch the bundled CLI with `PhotoCraft.AppImage --cli …`, including `--cli mcp`
for the stdio MCP server. A symlink named `photocraft-cli` also selects the CLI
through the AppImage runtime's `ARGV0`.

The launcher executes the CLI before desktop integration, removes only the
leading selector, and preserves arguments, stdin, stdout, stderr, exit status
and signals. README, development and release instructions include examples.
