## Summary
Adds read-only `Format::PhotoshopRaw` for Adobe Photoshop Raw files that include the standard retained header (channels, rows, columns, depth, interleave). Plain headerless streams still require explicit dimensions like Photoshop's File › Open dialog.

## Plan
- `photoshop_raw.rs` decoder with header sniffing and 8/16-bit interleaved/planar paths.
- Register format in `photocraft-codecs`; flat import falls back to `.raw` extension when magic is inconclusive.
- Document partial parity in `file-format-parity.md` and G10 in `gaps.md`.
