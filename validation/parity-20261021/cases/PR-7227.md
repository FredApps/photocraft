Fixes #7210

### Problem
Liquify's preview could only zoom by turning a mouse wheel over it. The issue is from macOS, where people usually zoom another way, and none of those worked:
- **Pinch.** A trackpad pinch arrives as egui's `Event::Zoom` (`zoom_delta`), which the preview ignored.
- **Keyboard.** ⌘+ / ⌘− / ⌘0 / ⌘1 weren't handled in Liquify. While the dialog was open with one of its controls focused, they went to the canvas behind it (`nav_keys`) and zoomed that.
- **Wheel steps.** The wheel zoom used its own smoothed curve (`exp(scroll / 200)`) instead of the app's ×1.1 per notch.

Photoshop's Liquify zooms with the usual zoom keys and with a pinch.

### Solution
`crates/ui-egui/src/liquify_ui.rs`:
- **Keys.** Zoom In / Zoom Out step the preview along the canvas's zoom ladder (`zoom_levels::step_in_range`, within the preview's 1 %–3200 %). Fit on Screen fits and centres it again. Actual Pixels is the dialog's 100 %.
  - They are found through the canvas commands' own shortcuts, including Edit › Keyboard Shortcuts overrides and ⌘+ typed as Plus, so a remapped Zoom In works here too.
  - The key press is consumed, so the canvas behind the dialog keeps its zoom.
  - On macOS the native menu's key equivalents come back to egui as key presses (`native_menu`), so they reach the dialog the same way.
- **Wheel and pinch.** The preview reads the wheel through `wheel_nav::read`, as the Navigator does:
  - a notch zooms ×1.1 about the pointer, and ⇧+wheel snaps to the next ladder step;
  - a pinch zooms about the pointer, unless Preferences › Enhanced Controls › Zoom with Trackpad Pinch is off; Windows and Linux touchpad pinches are already folded into pinch events app-wide;
  - a sideways scroll pans.
- **Zoom range.** The preview's range is named once (`ZOOM_MIN`, `ZOOM_MAX`) instead of repeated literals.

`crates/ui-egui/src/shortcuts.rs`: `nav_keys` is split so the lookup, `nav_shortcut`, can be reused: it returns which navigation command's shortcut was pressed. `nav_keys` behaves as before.

### Tests
`liquify_ui::tests` (both fail before this change):
- `zoom_shortcuts_zoom_the_preview_not_the_canvas`:
  - ⌘1 → 100 %, ⌘= → 200 %, ⌘+ → 300 %, ⌘− → 200 %, ⌘0 → fits again on the next frame;
  - the canvas view's zoom is unchanged.
- `pinch_and_wheel_zoom_the_preview_about_the_pointer`:
  - a ×2 pinch doubles the zoom and keeps the document point under the pointer;
  - one wheel notch is ×1.1;
  - a pinch does nothing with Zoom with Trackpad Pinch off.
