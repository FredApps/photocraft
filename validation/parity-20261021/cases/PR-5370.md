## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

The scoped_work function skipped error scopes when watched is true (always the case in the app because the canvas sets up health monitoring). But error scopes are needed on native platforms to catch synchronous validation errors (e.g. invalid buffer in queue.write_buffer). The health callbacks only handle device loss and async errors.

This fixes P12 (arrow-key nudge in a 150-layer document) which crashed with: wgpu error: Validation Error / Caused by: / In Queue::write_buffer / Buffer with pc_compose_uniforms label is invalid

Now scoped_work always uses error scopes on native (non-WASM) to catch validation/internal/OOM errors, while WebGPU relies on health callbacks for async errors.
