## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Polygonal Lasso now scrolls the canvas while the pointer rests near or just past an active viewport edge, including between vertex clicks with the button released. This lets a zoomed-in outline continue into an offscreen area without manually switching to navigation.

Fixes #2231.

Scrolling keeps placed vertices in document coordinates, uses the existing rotated, mirrored and pixel-aspect-aware view mapping and Overscroll bounds, and requests further frames for a stationary pointer. Returning to the interior, opening a dialog or using temporary navigation stops automatic motion. An unfinished polygon is tied to its starting document so switching documents or tools cannot later commit it to a different document. Shift-constrained segments remain supported while the view scrolls.
