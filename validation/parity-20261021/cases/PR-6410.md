Fixes #5712.

**Cause.** In a document with artboards, `canvas.rs` paints the pasteboard (the grey/dotted area between boards) *on top of* the composited image, over every canvas rect that isn't inside a board (`artboard_ui::pasteboard_rects`). Drawing a new artboard next to existing work puts that work outside every board, so it gets covered: "my original work just disappears, it's still there if I hover over layers". Photoshop shows layers that aren't in an artboard.

**Fix.** `pasteboard_rects` now subtracts the composite bounds (`photocraft_compose::composite_bounds`) of every visible top-level layer that isn't an artboard. The document's Background, and any layer whose bounds are unbounded (e.g. a fill layer) or cover the whole canvas, count as backdrop rather than loose work, so they keep the pasteboard. Boards still get their pasteboard between them as before.

**Tests.** New `layers_outside_the_boards_show_over_the_pasteboard` (a 20×20 loose pixel layer beside a board is not covered), `full_canvas_layers_keep_the_pasteboard` (the default white Background plus a full-canvas pixel layer leave the pasteboard intact) and `subtract_splits_around_holes`. The existing pasteboard test runs on the default white document again. `cargo test -p photocraft-ui-egui --lib artboard_ui` passes (8).
