## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Fixes #6426.





Automation roots were stored with `std::path::absolute` and matched as text. A root configured through a directory link or `..` could therefore reject the actual absolute location of a file inside its granted directory.





Resolve the trusted root once at startup and retain both its canonical and configured absolute spellings as names for the same held directory capability. Strip a matching component prefix, validate the remaining relative path, and keep every read, create and rename in cap-std. Windows ordinary/verbatim drive and UNC prefixes compare equivalently. Existing launch spellings, nonexistent output files and nested export directories keep working; request traversal, sibling prefixes, ungranted aliases and link escapes remain refused. Retargeting a launch-time link does not grant a new directory. Update the control-protocol documentation.
