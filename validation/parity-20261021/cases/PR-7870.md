## Pinned upstream reproduction and regression specification

In Photoshop on Windows, Ctrl+F4 closes the current document, just like Ctrl+W. In PhotoCraft only Ctrl+W was bound, so Ctrl+F4 did nothing.

## Change
- `crates/engine/src/prefs.rs`: add `("file.close", "Cmd+F4")` to `ALTERNATE_SHORTCUTS` (#3665's second-key table), compiled out on macOS. macOS uses Ctrl+F4 for window focus, and Photoshop for Mac has no such key.
- Ctrl+F4 goes through the same guarded `file.close` as Ctrl+W, so a document with unsaved changes still gets the save prompt. Like the other alternates, it can be removed in Edit › Keyboard Shortcuts.

## Tests
- New `shortcut_dispatch::tests::ctrl_f4_closes_the_document`: on a modified document Ctrl+F4 opens the save prompt and keeps the document open; on a saved one it closes it.
- The existing `no_duplicate_shortcuts` and prefs alternate-conflict tests pass, so the key is not bound to anything else.
- `cargo test -p photocraft-ui-egui --lib -- shortcut_dispatch:: shortcuts::tests::`, `cargo test -p photocraft-engine --lib -- prefs::`, and `cargo clippy -p photocraft-engine -p photocraft-ui-egui --all-targets -- -D warnings` all pass.
