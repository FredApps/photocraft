Fixes #7245

## Cause
An .atn Image Size descriptor with only a resolution and a resample mode imports as keepPrintSize:true. Strict export wrote that descriptor for a resolution-only command that never had keepPrintSize. After the round trip the command scaled pixels: an 8×8 document recorded as a resolution change to 144 ppi (no pixel scaling) came back as 16×16 at 144 ppi instead of 8×8.

## Fix
`image_size_to` now refuses to export a resolution-only Image Size with a resample mode unless `keepPrintSize` is true. The step is reported as skipped instead of silently changing meaning. A regression test checks that the refusal happens.

## Verified
- Regression tests `atn_cmds::tests::image_size_resolution_only_does_not_gain_keep_print_size`, `atn_cmds::tests::image_size_intentional_controls_still_round_trip`: fail on `main` without the fix and pass with it (`cargo test -p photocraft-engine --lib atn_cmds::tests::image_size_`).
- `cargo xtask ci` passes.

## Not changed
The import mapping in `image_size_from` is unchanged, so descriptors from Photoshop still import as keep-print-size. Explicit keepPrintSize:true and explicit width/height commands still round-trip as before. The separate resample:"none" case from #7189 is also untouched and still exports.
