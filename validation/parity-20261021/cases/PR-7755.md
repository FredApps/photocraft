Fixes #7668.

Crystallize with `{"cellSize":5,"seed":37}` gives identical pixels in direct execution and native action playback. Strict ATN export used to succeed without skipped steps, write only `ClSz`, and silently replay with seed 0 after import, changing the image without warnings.

Refuse an explicitly provided nonzero or malformed native seed when exporting the Crystallize event. The mapped `Crst` descriptor cannot carry PhotoCraft's seed. Missing and numeric-zero seeds retain the existing conversion. Strict Save Actions reports the action and step; opt-in `skipUnsupported` omits that step and reports its original action, index and command ID. The native action remains unchanged.

This is a separate commit based on main. It does not include the fractional-cell-size fix in #7721, and does not change native Crystallize, its random algorithm, ATN import, the shared integer converter, or PSD smart-filter mappings. No new Photoshop descriptor key is invented.

Regression coverage:

- 36 native cases: six nonzero seeds (including 37, 2^31 and u32::MAX), cell sizes 5/10, 8/16/32-bit synthetic RGB documents. Direct and native playback agree; strict export refuses the unrepresentable seed. Seed 37 is visibly distinguished from seed 0 at every tested depth and cell size.
- 27 direct/native/binary-ATN playback triples for absent/numeric-zero seeds, defaults, bounds and explicit pixel targets; inspect that the binary descriptor still contains only the existing cell-size key.
- Mixed actions: precise strict error, opt-in skip indices 1/3, supported command order and playback pixels preserved.
- Malformed seeds and non-pixel targets refused; the public `actions.save` command reports refusal/opt-in skip and leaves the native action's steps unchanged.
