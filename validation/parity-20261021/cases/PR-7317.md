## Summary
The Color panel can switch between HSB and RGB sliders under the colour field, so users (including color-blind users who asked on Discord) can edit colours by red, green and blue channels with optional dynamic gradient tracks.

## Plan
- `ColorPanelSliderMode` on `ColorPanelState` (`hsb` default, `rgb`).
- `rgb_sliders` alongside existing HSB sliders; mode dropdown on non-pro and pro Color tabs.
- Pro themes show RGB sliders when RGB mode is selected (field-only layout unchanged for HSB).
