## Summary

Bind the control listener before GPU/display initialization, and pass the bound listener to the server. An occupied port now exits promptly with a useful diagnostic and status 2.

```text
control startup
  validate token and workspace
  bind 127.0.0.1:port → on failure: report error, exit 2
  initialize display/GPU
  start server with bound listener
```

Fixes #6428.
