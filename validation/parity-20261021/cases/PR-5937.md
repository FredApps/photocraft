### Summary of Changes
- In `crates/compose/src/effects.rs`, corrected the discontinuity in `outline_share(cov, l)` by immediately returning `0.0` when `outside <= 1e-6`, preventing opaque pixel interiors (`cov=1.0, l=1.0`) from evaluating `rest <= 1e-6` and receiving 100% outside stroke share.
- In `composite_with_effects_prepared`, unified the outside stroke share calculation using `band * outline_share(...)` across raster and vector layers, eliminating the smudge artifact.
- Added regression test `outside_stroke_on_raster_layer_does_not_paint_inside_opaque_pixels` in `crates/compose/src/stroke_tests.rs`.
