## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Clipboard and canvas centers added signed coordinates before converting to floating point. Near the coordinate limits this panicked in checked builds and wrapped to an incorrect paste position in release builds. Convert each edge before adding, preserving normal centering and rounding behavior.
