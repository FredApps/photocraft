## Pinned upstream reproduction and regression specification

The following is source material from the approved PR, not a record of testing this combined build. Test the stated scenario, values and regression names in addition to the procedure above.

Crystallize was rebuilding jittered sites per pixel and accumulating cell averages it almost never used. Pointillize was rebuilding dot geometry and resampling its colour for every candidate pixel.

On a 24 MP RGB8 layer, the actual commands at small cell sizes now take about 140 ms:

| Command | Cell size | Before | After | Speedup |
|---|---:|---:|---:|---:|
| Crystallize | 10 | 560.8 ms | 137.5 ms | 4.08x |
| Pointillize | 5 | 430.5 ms | 146.4 ms | 2.94x |
| Crystallize | 100 | 1387.5 ms | 202.1 ms | 6.87x |
| Pointillize | 100 | 543.5 ms | 131.9 ms | 4.12x |

These are `Session::execute` timings, including the history commit. Five runs, median, 6000 x 4000, 16 workers on a c7i.4xlarge. Setup, hashing and GUI repaint are outside the clock.

Background layers have a smaller gain because the existing transparency restoration pass takes a large share of the time. At cell sizes 10/5, Crystallize goes from 891.5 to 441.1 ms (2.02x), Pointillize from 738.5 to 608.2 ms (1.21x). At size 100 they improve 3.42x and 1.94x. The report includes those rows and single-worker runs too.

What changed:

- Prepare jittered sites, dot radii and source colours once per cell in each tile. Read cell centres directly rather than materializing a dense halo where it is unnecessary.
- Only accumulate Crystallize averages for cells whose centres fall outside the image. Boundary sums keep the original row order and f32 rounding.
- For larger cells, certify horizontal spans using bounds on the actual rounded f32 distance scores. A span is filled only when one candidate's worst score beats every other candidate's best. Ambiguous spans split down to scalar pixels. No approximate bisectors or epsilon tests.
- Encode U8/U16/F32 output on the tile workers. The serial commit copies native bytes instead of converting every sample.

The old scalar implementations remain as independent fallbacks and test oracles. Site-grid scratch is capped; failed optional reservations keep the old path.

All 44 measured before/after configurations have identical full-output hashes. The command bench also verifies Undo and Redo. New scalar comparisons cover colour models, alpha, fractional cells, negative origins, boundary averages, nonfinite samples, soft selections, clamped extents and storage depths. Span tests include coordinates near f32 precision boundaries.
