Fixes #3660.

MCP server processes can remain alive indefinitely when a client stops communicating without closing its connection.

This change:
- Adds a 30-minute inactivity timeout to the MCP stdio transport.
- Shuts down idle servers even when the client leaves stdin open.
- Resets the inactivity timer whenever a request arrives.
- Preserves normal shutdown when stdin reaches EOF.
- Adds regression tests for abandoned connections and active clients.
- Documents the new lifecycle behavior.
