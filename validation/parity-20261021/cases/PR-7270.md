## Summary
In the Brushes panel, a search forced every group and nested folder open, so folders that held matching brushes couldn't be collapsed while the search was active (#7257). Search now respects the collapsed state, and clicking a folder header during a search closes it.

## What changed
- `crates/ui-egui/src/brushes_tab.rs`: a group or nested folder is open only when it isn't in the collapsed list. The `filtering` override (and the now-unused `filtering` field on `Draw`) is removed.
- `brushes_panel_groups_collapse_and_filter` is updated: with a filter active, collapsed groups stay collapsed.
- New `brush_search_allows_collapsing_nested_folders` kittest: with a search active, clicking a nested folder header that contains matches collapses it and hides its matches.

## Testing
- Covered by the updated and new brush panel kittests in `crates/ui-egui/src/brush_panel_tests.rs`.
- Not tested by hand on macOS.
